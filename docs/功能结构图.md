## 功能结构图说明

### 七大分组连线清晰标注
1. **客户端路由与生命周期连线**：顶部菜单/设置按钮 + 中央品牌 Logo + 底部搜索栏 → 相机/相册/滑动手势抽屉 → 识别结果页
2. **拍照识别与自省状态机主流程**：VLM 识别 → 置信度检查 → 自省重试循环 → 意图对齐引导卡片
3. **识别达标后流向检索与比价**：置信度达标 → 多平台并行检索
4. **检索后流向比价与 Rerank 精排**：Levenshtein 初筛 → Embedding 精排 → SEO 垃圾词过滤
5. **属性修正反哺闭环数据流**：用户纠错数据 → 纯结构化操作重新检索，完全不调用LLM
6. **自然语言追加筛选流 (SSE)**：筛选输入 → LLM仅做意图解析器 → SQL级过滤商品集 → SSE逐条推送
7. **设置与账户管理模块**：个人信息编辑 → 登录/注册 → 退出登录；外观切换(浅色/深色/跟随系统) → 全局主题色适配；字体大小(0.85x/1.0x/1.15x) → 全局字号缩放；缓存清理 → 清除 Flutter 图片缓存；消息通知偏好 → 推送/应用内提醒开关；中英文语言切换 → 全局文案即时更新；及用户认证系统（JWT Bearer Token + bcrypt）和收藏/浏览记录（个人中心 Tab 页）
### 核心亮点完整闭环
- ✅ **Self-Correction 自省状态机**：AI3 → AI1 形成完整循环，多次失败后进入意图对齐引导卡片
- ✅ **属性修正纯结构化操作**：剔除LLM依赖，速度更快，无额外Token开销
- ✅ **策略模式熔断降级**：FD1 → FD2 异常自动切换，零外部依赖兜底
- ✅ **同款对齐 Rerank**：三步式处理，彻底解决电商 SEO 垃圾词问题
- ✅ **LLM仅做意图解析器**：SQL级过滤商品集，避免大上下文处理
- ✅ **SSE流式局部刷新**：网络中断前端自动重连，无需复杂分布式流状态
