# 项目分工说明

## 项目概览
**项目名称**：SnapShop - AI 拍照识物与智能比价购物助手
**参赛方向**：AI 全栈创新赛道
**总开发周期**：约 20 天
**完成方式**：个人独立完成

---

## 完成人

本项目由本人独立完成，涵盖从需求分析、系统架构设计、后端开发、前端开发、AI 工程到质量保障的全链路工作。

---

## 核心模块技术栈清单

### 后端（Python + FastAPI）
- **Web 框架**：FastAPI 0.115.x，ASGI 异步架构
- **数据库**：SQLAlchemy 2.0 Async + SQLite/PostgreSQL
- **缓存**：Redis 5.x 连接池，带 LRU 内存降级兜底
- **AI 能力**：火山引擎 Ark VLM + LLM（Doubao-Seed-2.0）
- **电商平台**：京东联盟 API + 拼多多联盟 API + Mock 数据源兜底
- **安全**：JWT 认证 + bcrypt 密码哈希 + 全局限流

### 移动端（Flutter 3.x）
- **状态管理**：flutter_riverpod 2.x
- **路由**：go_router
- **网络层**：dio 4.x
- **相机**：image_picker + camera
- **国际化**：flutter_localizations 完整多语言支持
- **主题**：自适应亮色/暗色 + 字体大小 4 档调节
