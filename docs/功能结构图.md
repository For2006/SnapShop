# SnapShop — 功能结构图

> **项目**：SnapShop — AI 拍照识物与智能比价购物助手

---

```
│   ├── 中央品牌 Logo + 标语（进场动效）
│   ├── 顶部按钮栏（菜单→历史抽屉 / 设置→设置页）
│   ├── 底部搜索栏（相机 / 相册 / 文字搜索三个入口）
│   ├── 滑动手势历史抽屉面板
│   └── 相册选择面板（底部抬升）
├── 相机模块
│   ├── 系统相机唤起
│   └── 拍照 → 自动压缩 → 上传
├── 识别结果模块
│   ├── 商品类目与属性标签展示
│   ├── 属性修正（点击标签编辑）
│   ├── 智能建议卡片横向滚动
│   └── 跨平台价格汇总条
├── 商品列表模块
│   ├── 商品卡片瀑布流（商品图/名称/价格/平台/标签/评分/销量/收藏按钮）

    ├── 智能建议服务（规则引擎 + LLM 混合生成）
    ├── 自然语言筛选服务（LLM 解析 + 正则回退）
    └── 数据存储（PostgreSQL + Redis + MinIO）
```

## 核心链路

### 拍照识物链路
```
拍照/选图 → 自动压缩 → multipart 上传 → VLM 识别商品属性
→ 返回属性标签 + 预设建议卡片 → 后台异步多平台搜索
→ 前端轮询获取商品 → 跨平台比价聚合 → 展示
```

### 文字搜索链路
```
输入关键词 → POST /search → 跳过 VLM → 直接多平台搜索
→ 返回商品列表 + 预设建议卡片
```

### 自然语言筛选链路
```
输入筛选文本 → LLM 解析为结构化过滤条件（有正则回退）
→ SSE 流式逐条推送匹配商品 → 实时渲染
```

### 属性修正链路
```
点击属性标签 → 弹出编辑面板 → 输入新值 → PATCH 请求
→ 后端组装新关键词重新检索（纯结构化，不调用 LLM）
```

## AI Pipeline

```
┌─────────────────────────────────────────────────────┐
│                    VLM 视觉识别                       │
│  图片 → ArkVLMClient → 结构化 JSON → Pydantic 校验   │
│        失败 → Self-Correction 自省 (max 2次)         │
│        仍失败 → 意图引导卡片                            │
├─────────────────────────────────────────────────────┤
│                    LLM 智能决策                       │
│  识别结果 + 平台统计 → ArkLLMClient                   │
│  → 建议卡片生成（规则+LLM 融合去重）                     │
│  → 自然语言筛选解析（LLM+Regex 策略模式）               │
├─────────────────────────────────────────────────────┤
│                     熔断降级                          │
│  策略模式三级熔断：LLM → RegexOffline → 空列表降级      │
│  指数退避重试：429/5xx → 1s→2s→4s（最多3次）           │
└─────────────────────────────────────────────────────┘
```
